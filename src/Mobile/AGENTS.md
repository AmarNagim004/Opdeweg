This is the Opdeweg Expo / React Native app (TypeScript). It runs as an Expo **development build**
(native modules: LiveKit/WebRTC, background location, the local `modules/opdeweg-drive-service`).

## Conventions

- Navigation uses **React Navigation** (native stack + bottom tabs) in `src/navigation` — not Expo Router.
- Feature code lives in `src/features/<feature>`; shared UI in `src/components`; platform/service
  wrappers in `src/services`; one Zustand store per concern in `src/store`.
- The backend is authoritative for proximity and voice membership; the app mirrors server state.
- Never put secrets in `EXPO_PUBLIC_*` variables. Never log coordinates or tokens.
- `ios/` and `android/` are generated by `npx expo prebuild` — configure native behaviour in
  `app.config.ts`, config plugins, or the local module; never edit generated folders.
- Install packages with `npx expo install <package>` so versions match the SDK.
